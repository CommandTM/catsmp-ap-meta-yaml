# The Cat SMP Archipelago Meta YAML
This Meta YAML is used in the bi-monthly private [Archipelago](https://archipelago.gg/) events hosted in a friend group called Cat SMP.

## Current Restrictions
- Jigsaw
    - Piece Bundles are forced to ten
    - Forces all Jigsaw filler to be local if `add_fillers` is true
    - Clues are forced on
